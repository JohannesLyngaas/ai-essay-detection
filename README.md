# Detecting AI-Generated Student Essays

Can a classifier tell essays written by students from essays written by large language models? And does it still work on essay topics it has never seen?

This project compares classical text classifiers (TF-IDF with logistic regression and a linear SVM) with fine-tuned transformer encoders (DistilBERT and ModernBERT) on the [DAIGT v2](https://www.kaggle.com/datasets/thedrcat/daigt-v2-train-dataset) dataset of roughly 45,000 essays. It is my course project in TDT13 at NTNU, autumn 2026.

> **Status:** work in progress. Results are added as the experiments finish.

## Research questions

1. How well do TF-IDF + logistic regression and a linear SVM separate student-written and AI-generated essays?
2. How much better are fine-tuned transformers, and does a newer encoder (ModernBERT) improve on DistilBERT?
3. How much does performance drop on essay topics the models have not seen during training?
4. Which essays do the models get wrong, and what do they have in common?

## Approach

**Data.** DAIGT v2 contains student essays and essays generated by several language models, each written for one of a set of essay prompts (topics). Duplicates and essays with conflicting labels are removed before splitting.

**Two splits.**

- *Random split:* a stratified 80/10/10 train/val/test split. The standard setup.
- *Topic split:* whole topics are held out for validation and test. This shows whether a model learns writing style or just memorises topic words.

**Models.** Both classical models use the same TF-IDF features, so they differ only in the classifier. The transformers are fine-tuned with identical settings, so they differ only in the pretrained encoder.

**Evaluation.** Accuracy, F1 for the AI class, macro-F1, AI recall, the false positive rate, AI recall at a false positive rate of 1 %, ROC-AUC and confusion matrices, followed by an error analysis by topic, essay length and source model.

The two test sets differ in class balance: 39 % AI in the random split, 18 % in the topic split. Accuracy and F1 depend on that balance, so the two splits are compared mainly on AI recall, false positive rate and ROC-AUC, which do not.

## How to reproduce

### 1. Set up

Requires [uv](https://docs.astral.sh/uv/getting-started/installation/) and git.

```bash
git clone https://github.com/JohannesLyngaas/ai-essay-detection.git
cd ai-essay-detection
uv sync              # creates .venv/ and installs all dependencies
uv run pytest        # quick check that everything works
```

### 2. Get the data and make the splits

Download the dataset into `data/raw/` (see [data/README.md](data/README.md)), then:

```bash
uv run python -m essaydetect.data
```

### 3. Run an experiment

```bash
uv run python -m essaydetect.train --config configs/lr_topic.yaml
```

Each run saves `metrics.json` and `predictions.csv` in `results/<experiment>/`. To collect all finished runs into one table:

```bash
uv run python -m essaydetect.evaluate
```

The classical models run on a laptop CPU. The transformers need a GPU (see below).

### Running the transformers on Kaggle

In a Kaggle notebook with the DAIGT v2 dataset attached, and GPU and internet turned on:

```bash
!git clone https://github.com/<your-username>/ai-essay-detection.git
%cd ai-essay-detection
!pip install -q -e .
!python -m essaydetect.data --raw /kaggle/input/daigt-v2-train-dataset/train_v2_drcat_02.csv
!python -m essaydetect.train --config configs/distilbert_topic.yaml
```

Check the exact input path in the notebook's *Input* panel. Download the new folder in `results/` afterwards and commit it.
